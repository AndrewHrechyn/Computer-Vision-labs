# Computer-Vision-labs

This repository contains a set of practical computer vision laboratory assignments. The first lab is an introductory exercise focused on working with digital images in Python using OpenCV, NumPy, and Matplotlib.

In Lab 1, the notebook loads several sample images and displays them to explore the basic workflow of computer vision. The main goal is to become familiar with how images are stored, how pixel values are represented in arrays, and how visual content can be inspected with simple programming tools. The lab starts by checking the installed versions of OpenCV and NumPy, then proceeds to read image files and show them using a custom plotting function.

The images used in the lab represent different visual patterns and scenes: a nighttime bridge/city scene with bright lights, colorful square blocks, and leaves with different shades of green. These examples help students understand color, brightness, contrast, and image structure in an intuitive way.

Overall, this lab introduces the fundamental concepts of computer vision: image loading, visualization, and understanding images as arrays of numerical data. It serves as the foundation for more advanced topics such as image processing, filtering, segmentation, and feature extraction in later labs.
